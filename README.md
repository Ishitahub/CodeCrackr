# 🚀 CodeCrackr – A Modern Coding Practice Platform

Live Demo: [https://ishitahub.github.io/CodeCrackr/](https://ishitahub.github.io/CodeCrackr/)

CodeCrackr is a sleek, responsive coding practice platform designed to help users sharpen their problem-solving skills. Built with React, it offers a clean user interface, dark/light theme toggle, a leaderboard, and a structured list of practice problems.

---

## 🌟 Features

- ⚙️ **Interactive Practice Page** – Solve curated programming problems.
- 🎯 **Leaderboard** – Displays top performers based on problem-solving stats.
- 🌗 **Dark/Light Theme Toggle** – Enhances accessibility and user comfort.
- 📱 **Responsive Design** – Works smoothly on desktop, tablet, and mobile.
- 🧭 **Sidebar Navigation** – Easy navigation between sections.
- 🧑‍💻 **Login & Register Pages** – Placeholder for future authentication.
- 🔥 **Deployed via GitHub Pages** – Easily accessible online.
